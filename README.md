# Afficionado Coffee Roasters – Retail Sales Analytics

## Project Overview

This project focuses on analysing retail sales data from Afficionado Coffee Roasters. The main objective is to understand sales performance, identify product trends and generate useful business insights through an interactive dashboard.

Python is used for data cleaning, exploratory data analysis and visualisation. Streamlit is used to build the interactive dashboard.

## Project Objectives

- Analyse overall retail sales performance.
- Compare revenue across store locations.
- Identify the best-performing product categories.
- Analyse sales by transaction hour.
- Identify the most popular products.
- Develop an interactive sales analytics dashboard.

## Dataset Information

The dataset contains 149,116 transaction records from three store locations.

- Total Transactions: 149,116
- Store Locations: 3
- Product Categories: 9
- Total Quantity Sold: 214,470
- Total Revenue: $698,812.33

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the required libraries:

```bash
py -m pip install -r requirements.txt
```

4. Run the dashboard:

```bash
py -m streamlit run app.py
```

5. Open the local URL displayed in the terminal.
